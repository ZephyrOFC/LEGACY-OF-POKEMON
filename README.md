# Legacy of Pokémon

**Legacy of Pokémon** is a Pokémon Emerald-based ROM hack that reimagines the Johto adventure in classic GBA style, featuring updated visuals, DexNav support, and quality-of-life improvements.

---

## Features

- Johto region in GBA style
- Expanded Emerald-based engine
- DexNav support
- Updated visuals
- Quality-of-life improvements
- Custom title screen
- Classic Pokémon adventure feel

---

## Base ROM

This patch is made for:

**Pokémon Emerald Version (U)**

Recommended clean ROM SHA1:

```text
f3ae088181bf583e55daf962a92bb46f4f1d07b7
```

---

## How to Play

1. Get a clean Pokémon Emerald Version (U) ROM.
2. Apply the `.ups` patch using a UPS patcher such as **NUPS**, **Tsukuyomi UPS**, or **Floating IPS**.
3. Open the patched ROM in a GBA emulator.

Recommended emulators:

- mGBA
- VisualBoyAdvance-M
- RetroArch with a GBA core
